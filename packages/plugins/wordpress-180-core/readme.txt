The official unified 180 Core plugin for WordPress & WooCommerce. Combines 1-Click Universal Authentication with Sovereign 180 Pay Gateway.

== Description ==

180 Core for WordPress seamlessly brings the power of the 180 Core platform to your WordPress and WooCommerce site with zero coding.

Features:
* **180 Identity (Universal SSO)**: 1-Click login with WhatsApp 1-Tap OTP, Google SSO, Passkeys, and universal @usernames.
* **180 Pay (WooCommerce Payment Gateway)**: Accept payments via UPI, QR, Credit/Debit cards, NetBanking, and Instant 180 Wallet.
* **Independent Toggles**: Use Identity only, Pay only, or both!
* **Single Credential**: Set your Client ID and Client Secret once in WP Admin.
* **Instant Webhook Sync**: Auto-transitions WooCommerce orders to Processing upon payment completion.

== Installation ==

1. Upload `180-core.zip` via WordPress Admin (Plugins → Add New → Upload Plugin).
2. Activate the plugin.
3. Navigate to **180 Core** in your WordPress admin menu.
4. Enter your **Client ID** and **Client Secret** from your 180 Developer Console (https://developer.180core.cloud).
5. Toggle 180 Identity and 180 Pay as desired.
